
# Willey Ecommerce 

### 1.	Project Title / Headline
Executive Sales & Performance Analytics Dashboard — A end-to-end Power BI solution for tracking organizational revenue growth, time-intelligence comparisons, and regional performance trends.

### 2.	Short Description / Purpose
This Power BI dashboard aggregates cross-channel sales and customer interaction data to provide leadership with actionable insights into revenue streams, historical growth trends, and regional performance. It enables data-driven decision-making by replacing static reports with dynamic, interactive period-over-period visualizations.

### 3.	Tech Stack
The dashboard was built using the following tools and technologies:
•	📊 Power BI Desktop – Main data visualization platform used for report creation.<br>
•	📂 Power Query – Data transformation and cleaning layer for reshaping and preparing the data.<br>
•	🧠 DAX (Data Analysis Expressions) – Used for calculated measures, dynamic visuals, and conditional logic.<br>
•	📝 Data Modeling – Relationships established among tables <br>
•	📁 File Format – .pbix for development and .png for dashboard previews.


### 4.	Features / Highlights
The best dashboard explanation format. <br>
•	Business problem <br>
•	Goal of the dashboard <br>
•	Walk through of key visuals (briefly!) <br>
•	Business impact & Insights

•	Business Problem
Management lacked visibility into period-over-period sales performance (MTD, QTD, YTD) across regional channels, making it difficult to detect underperforming territories or accurately compare current figures against prior years. Manual spreadsheet reporting led to delayed insights and inconsistent data models.

Key questions such as:
Which regions offer the most family-friendly or expert-level skiing?
Where is summer skiing available?
What countries have the most well-equipped resorts?
… are difficult to answer quickly with raw data.

•	Goal of the Dashboard
To build a centralized, automated analytics model that equips business leaders with dynamic period comparisons, customer segmentation, and custom time-intelligence filtering to optimize revenue growth and operational planning.

•	Walkthrough of Key Visuals
Executive KPI Cards: Top-level metrics displaying total Revenue, YTD Sales, and Year-over-Year Growth ($YOY$) with conditional formatting indicators.<br>
Time-Intelligence Trend Chart: Interactive line and bar visual utilizing DATEADD and TOTALYTD DAX calculations to plot current sales against Prior Year ($PY$) and Same Period Last Month ($SPM$).<br>
Regional & Category Breakdown: Matrix visual allowing drill-down capabilities from geographic territories into specific product categories and customer segments.<br>
Dynamic Slicer Panel: Custom controls enabling stakeholders to slice data by dynamic date ranges, rolling windows (Rolling 30D, Rolling 12M), and product lines.

•	Business Impact & Insights
Marketing Optimization: Travel agencies can use this dashboard to identify key selling points for different demographics (e.g., child-friendly resorts or expert terrain).
Strategic Expansion: Resort developers can spot underdeveloped regions with high potential.
Vacation Planning: Tourists can plan trips based on slope availability, elevation, and terrain difficulty.
Regional Analysis: Governments and tourism bodies can analyze competitiveness by region.
